# Roadmap

The 1.0 command set covers local Takeout inspection, planning, export, integrity verification, source comparison, interrupted-export recovery, and a read-only local viewer. It also includes an explicit Immich adapter for server version 3.3.1. Check the [Releases page](https://github.com/Pastalikek65/archivebridge/releases) for currently available versions and their platform-specific evidence; no version inherits another version's results.

The adapter transfers original media bytes with a generated minimal date-only XMP sidecar containing the known Takeout UTC date. Immich 3.3.1 must process that date, and ArchiveBridge checks `fileCreatedAt`, `fileModifiedAt`, `ExifDateTimeOriginal`, and the full remote original before the upload is ready or album changes begin. Takeout does not provide the original filesystem modification time; the source date is used for Immich's required date fields. Original media bytes and embedded EXIF remain unchanged. Raw Takeout JSON sidecars are not transferred, and sidecar caption or GPS fields are not mapped. A bounded worker timeout or cancellation after upload acceptance leaves the remote asset ID in the partial report for explicit resume. These limits describe current behavior, not commitments about future releases.

Further Immich server versions, additional source formats, optional metadata mapping, and filesystems without hard-link support may be considered separately. Any such work requires its own implementation and version-specific verification. The current adapter does not delete remote content or claim to identify every item in an account.

Historical verification for an earlier release remains scoped to the version, commit, platforms, packages, and checks recorded for that release. It does not establish the behavior or qualification of a later version or of the Immich adapter.
